# Paperless-Arweave — Frontend

A compact React + TypeScript frontend for browsing, verifying and downloading documents that have been archived to
Arweave. The app provides a simple document management UI and a wallet-based authentication flow using the Wander
wallet.

## Key features

- Browse document lists associated with a wallet
- View document details and Arweave transaction IDs
- Download documents stored on Arweave under a wallet address
- Lightweight UI focused on secure access and easy integration with the backend

## Tech stack

- TypeScript
- React
